地图筛选器使用教程

使用说明

本工具用于快速浏览与筛选《黑夜君临》地图种子：支持直接浏览全部种子，或按夜王/地图/兴趣点逐步缩小范围。

快速上手

  1. 直接浏览：左侧“查看不同地图种子”列表默认展示全部种子，点击任意编号即可查看大图（方向键可切换）。
  2. 条件筛选（可选）：可选择夜王与/或地图以缩小范围：
    • 仅选夜王：显示该夜王的全部种子
    • 仅选地图：显示该地图的全部种子
  3. 兴趣点筛选（可选）：先选择地图，开启“兴趣点筛选模式”，在画布上点击橙色点标注实际看到的内容，系统会自动过滤结果。

操作提示

  • 标注：左键点击橙色点，在弹出的菜单里选择该点位实际看到的建筑（教堂 / 法师塔 / 村庄 / 大教堂 / 遗迹 / 湖沼 / 锻造村 / 主城 / 马车等等，菜单按该点位可能出现的类型给出，带图标）；右键删除标记；可使用“移除所有兴趣点”清空所有标记。
  • 每个点位只需要标注能确定的那些：没标注的点位不参与筛选。
  • “该点位没有建筑”用于标注你确认该点位是空的（大空洞尤其常用）。
  • 为 0 条结果时，可重置地图或减少限制。
  • 点击种子图片可在新标签页中打开。
  • 开启兴趣点筛选前需先选择【特殊地形】。
